# JSSBA Retail Platform

Enterprise platform transformation project.

## Objective

Transform JSSBA Retail Ltd from a manually managed startup environment into a fully automated platform leveraging:

- AWS
- Terraform
- Docker
- Kubernetes
- Ansible
- AWX
- GitHub Actions
- Prometheus
- Grafana
- Loki

## Deliverables

- Infrastructure as Code
- Configuration Management
- Continuous Delivery
- Monitoring
- Centralized Automation
