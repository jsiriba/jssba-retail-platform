# Day 03 - Docker Networking and Volumes

## Topics Covered

- Container IP addresses
- Docker networking
- Port publishing
- Docker volumes
- Data persistence
- Docker Compose

## Key Lessons

Containers are temporary.

Volumes are persistent.

Container ports are private.

Ports must be explicitly published.

Infrastructure can be described as code using Docker Compose.
